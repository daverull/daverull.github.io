Политика конфиденциальности

Приложение «KidCity Analytics» — внутренний инструмент магазина КидСити (г. Алматы, ул. Радостовца, 270).

Приложение используется только владельцем магазина для просмотра статистики собственных аккаунтов КидСити в YouTube и TikTok (просмотры, подписчики, лайки, география и источники зрителей). Доступ — только на чтение.

Приложение не публикует, не изменяет и не удаляет видео и другие данные, не собирает данные других пользователей и не передаёт полученную статистику третьим лицам. Данные хранятся только для внутренней аналитики магазина.

Отозвать доступ можно в любой момент в настройках аккаунта Google: myaccount.google.com/permissions.
