Политика конфиденциальности

Приложение «KidCity Analytics» — внутренний инструмент магазина КидСити (г. Алматы, ул. Радостовца, 270).

Приложение используется только владельцем магазина для просмотра статистики собственных аккаунтов КидСити в YouTube и TikTok (просмотры, подписчики, лайки, география и источники зрителей), а также для внутреннего анализа качества обслуживания в собственном WhatsApp Business магазина (время ответа, обращения без ответа, частые вопросы о товарах). Доступ — только на чтение.

Приложение не публикует, не изменяет и не удаляет видео и другие данные, не собирает данные других пользователей и не передаёт полученную статистику третьим лицам. Данные хранятся только для внутренней аналитики магазина.

Переписка WhatsApp используется только внутри магазина для контроля качества обслуживания и улучшения ассортимента; она не передаётся третьим лицам и не используется для рассылок.

Отозвать доступ можно в любой момент в настройках аккаунта Google: myaccount.google.com/permissions.
